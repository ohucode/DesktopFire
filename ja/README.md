# Macに、小さな焚き火を

文章を書くときも、本を読むときも。作業スペースの片隅で、静かに揺れる炎を楽しみませんか。**焚き火（Desktop Fire）**は、デスクトップに薪と炉を表示するmacOSのメニューバーアプリです。

## 好きな場所に、自分だけの焚き火を

- **好きな場所に配置** — 炉をドラッグして移動し、サイズを50%、70%、100%から選べます。
- **時間とともに変わる薪** — 着火から炎、赤く光る炭、灰へと変化します。燃焼時間は30分から8時間まで選べます。
- **シンプルな操作** — メニューバーから表示・非表示、ディスプレイの選択、すべてのデスクトップへの表示、ログイン時の起動を設定できます。
- **作業になじむ表示** — ポインタが近くに留まると焚き火が薄くなり、離れると元に戻ります。
- **音のない焚き火** — 音声を再生せず、炎の風景を楽しめます。

## 基本の焚き火は無料

オークの薪、ストーンリングの炉、基本の炎の色を無料で使えます。火をつけ直す回数にも制限はありません。

もっと多彩な組み合わせを楽しみたい方には、**Desktop Fire Plus**をご用意しています。1回の購入で、追加の薪5種類、炉8種類、すべての炎の色を利用できます。サブスクリプションはありません。価格はアプリ内の購入画面でご確認ください。

## Macのための小さな風景

macOS 14以降に対応し、韓国語・英語・日本語で利用できます。別途アカウントを作成する必要はなく、表示位置やカスタマイズの設定はMacに保存されます。
