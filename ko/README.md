# 당신의 Mac에 작은 모닥불을 놓아보세요

글을 쓰거나 책을 읽는 시간, 작업 공간 한쪽에서 조용히 타오르는 불꽃을 만나보세요. **모닥불(Desktop Fire)**은 바탕 화면에 장작과 화로를 표시하는 macOS 메뉴 막대 앱입니다.

## 나만의 자리에, 나만의 모닥불

- **원하는 곳에 놓기** — 화로를 드래그해 옮기고 크기를 50%, 70%, 100%로 조절하세요.
- **시간에 따라 변하는 장작** — 점화부터 불꽃, 붉은 숯, 재까지 이어지는 모습을 감상하세요. 연소 시간은 30분부터 8시간까지 선택할 수 있습니다.
- **간편한 조작** — 메뉴 막대에서 표시와 숨김, 디스플레이 선택, 모든 데스크탑 표시, 로그인 시 실행을 설정하세요.
- **작업 중에도 자연스럽게** — 커서가 가까이 머무르면 모닥불이 흐려지고, 멀어지면 다시 선명해집니다.
- **소리 없이 즐기는 불꽃** — 오디오 재생 없이 시각적인 모닥불을 즐기세요.

## 기본 모닥불은 무료

참나무 장작, 스톤링 화로, 기본 불꽃 색상을 무료로 사용할 수 있습니다. 다시 불붙이기에도 횟수 제한이 없습니다.

더 다양한 조합을 원한다면 **Desktop Fire Plus**를 만나보세요. 한 번 구매하면 추가 장작 5종, 추가 화로 8종, 모든 불꽃 색상을 사용할 수 있습니다. 구독은 없습니다. 가격은 앱 내 구매 화면에서 확인할 수 있습니다.

## Mac을 위한 작은 풍경

macOS 14 이상에서 사용할 수 있으며 한국어, 영어, 일본어를 지원합니다. 별도 회원가입 없이 시작할 수 있고, 화면 위치와 꾸미기 설정은 Mac에 저장됩니다.
