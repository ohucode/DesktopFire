# 모닥불 이용 지원

모닥불(Desktop Fire)은 macOS 14 이상에서 사용하는 메뉴 막대 앱입니다.

## 시작하기

1. 앱을 실행한 뒤 메뉴 막대의 불꽃 아이콘을 클릭하세요.
2. 화로를 드래그해 원하는 위치에 놓으세요.
3. **꾸미기**에서 장작, 화로, 불꽃 색상, 크기와 연소 시간을 선택하세요. 일부 꾸미기 항목은 플러스팩 구매가 필요합니다.
4. 메뉴에서 모닥불을 숨기거나 다시 표시하고, 불을 끄거나 다시 불붙일 수 있습니다.

## 자주 묻는 질문

### 앱을 실행했는데 Dock에 보이지 않아요

모닥불은 메뉴 막대에서 조작합니다. 화면 위쪽 메뉴 막대의 불꽃 아이콘을 확인하세요.

### 모닥불이 보이지 않아요

메뉴 막대에서 표시 상태와 선택된 디스플레이를 확인하세요. **항상 다른 창 위에 표시**를 껐다면 다른 창에 가려질 수 있습니다. 이때 **모닥불 앞으로 가져오기**를 사용하세요. 다른 데스크탑에서도 보려면 **모든 데스크탑에 표시**를 켜세요.

### 커서를 가까이 가져가면 흐려져요

작업을 방해하지 않도록 커서가 근처에 잠시 머무르면 투명도가 낮아집니다. 커서를 멀리 옮기면 돌아옵니다. 화로를 드래그하거나 메뉴를 조작하는 동안에는 선명하게 표시됩니다.

### 불이 꺼지고 재만 남았어요

선택한 연소 시간이 지나면 자연스럽게 꺼집니다. **다시 불붙이기**로 새 모닥불을 시작하세요. 숨김이나 Mac의 잠자기 중에도 연소 시간은 흐릅니다. 앱을 종료한 뒤 다시 실행하면 새 연소로 시작합니다.

### 타닥거리는 소리가 들리지 않아요

현재 버전에는 소리가 포함되어 있지 않습니다.

### 무료 기능과 플러스팩의 차이는 무엇인가요?

참나무, 스톤링, 기본 불꽃 색상과 횟수 제한 없는 다시 불붙이기는 무료입니다. 플러스팩은 추가 장작 5종, 화로 8종과 모든 불꽃 색상을 제공하는 일회성 인앱 구매입니다. 구독 상품이 아닙니다.

### 구매한 플러스팩이 적용되지 않아요

인터넷 연결과 구매할 때 사용한 Apple 계정으로 Mac App Store에 로그인했는지 확인한 뒤, 앱의 **플러스 팩 → 구매 복원**을 실행하세요. 구매 승인이 대기 중이라면 승인 후 다시 확인하세요. 계속 문제가 발생하면 오류 메시지와 함께 문의해 주세요.

### 구매 화면에 상품이나 가격이 나오지 않아요

인터넷 연결을 확인한 뒤 플러스팩 창에서 스토어를 다시 불러오세요. 잠시 후에도 해결되지 않으면 앱을 다시 실행해 주세요.

### 환불은 어떻게 요청하나요?

Apple의 [문제 신고 페이지](https://reportaproblem.apple.com/)에서 구매 내역을 확인하고 환불을 요청할 수 있습니다. 환불 가능 여부는 Apple의 절차에 따라 결정됩니다.

### 로그인 시 자동 실행을 바꾸고 싶어요

앱의 **설정 → 로그인 시 자동 실행**에서 변경하세요. macOS의 승인이 필요한 경우 메뉴의 시스템 설정 열기를 사용해 로그인 항목을 확인하세요.
