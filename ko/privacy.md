# 개인정보 처리방침

시행일: 2026-10-31

운영자 **Daehyun Kim**(이하 “운영자”)는 모닥불(Desktop Fire) 앱과 지원 과정에서 정보를 다음과 같이 처리합니다.

## 1. 앱 사용 중 처리하는 정보

모닥불은 별도 회원가입을 요구하지 않으며, 사용자의 이름, 이메일, 연락처, 위치, 화면 내용, 키보드 입력을 수집해 운영자의 서버로 전송하지 않습니다. 광고·사용자 추적·행동 분석 SDK를 사용하지 않으며, 운영자가 별도의 앱 이용 기록 수집 서버를 운영하지 않습니다.

앱은 기능 제공을 위해 다음 정보를 사용자의 Mac에 저장합니다.

- 화로 위치와 크기, 장작·화로 종류, 불꽃 색상과 연소 시간
- 표시 여부, 창의 표시 방식, 디스플레이 선택
- 첫 실행 안내 표시 이력

화로의 투명도 조절과 디스플레이 배치를 위해 현재 커서 위치와 화면 정보를 기기 안에서 사용합니다. 이 정보로 사용자의 화면이나 입력 내용을 기록하지 않으며 운영자에게 전송하지 않습니다. 로그인 시 실행 설정은 macOS의 로그인 항목 기능으로 관리합니다.

## 2. 인앱 구매

플러스팩 구매와 복원은 Apple의 App Store 및 StoreKit을 통해 처리됩니다. 앱은 상품 정보와 검증된 거래 정보(상품 식별자, 구매 권한 및 취소·철회 상태 등)를 사용해 플러스팩 사용 가능 여부를 확인합니다. 앱이 이 거래 정보를 운영자의 서버로 전송하지는 않습니다.

운영자는 앱을 통해 사용자의 결제 카드 번호나 Apple 계정 비밀번호를 받지 않습니다. Apple이 결제, 거래 기록 및 App Store 서비스와 관련하여 처리하는 정보는 [Apple의 App Store 개인정보 안내](https://www.apple.com/legal/privacy/data/en/app-store/)에 따릅니다.

## 3. 지원 문의

이메일로 문의하면 발신 이메일 주소, 문의 내용과 사용자가 직접 첨부한 파일을 문제 확인과 답변 목적으로 처리합니다. 불필요한 개인정보를 보내지 마세요.

문의 정보는 문의 처리 및 후속 대응을 위해 **문의 처리 완료 후 최대 90일간** 보관한 뒤 삭제합니다. 법령에 따른 보관 의무가 있는 경우에는 해당 사유와 기간에 따라 보관합니다.

지원 문의는 Google이 제공하는 Gmail을 통해 수신하고 관리합니다. 이메일 주소, 문의 내용 및 첨부파일은 거주 국가 밖에 있는 Google 서버에 저장되거나 처리될 수 있습니다. 자세한 내용은 [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)을 참고하세요.

GitHub Issues에 남긴 글은 공개될 수 있으며 GitHub 계정 정보와 함께 표시됩니다. GitHub 이용에 따른 정보 처리는 [GitHub 개인정보 처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)에 따릅니다.

## 4. 웹페이지 이용

이 지원·소개 웹페이지에는 운영자가 추가한 광고 추적 도구나 방문자 분석 스크립트가 없습니다. GitHub Pages로 제공되는 페이지를 방문하면 GitHub가 보안 목적으로 방문자의 IP 주소를 기록·보관합니다. 자세한 내용은 [GitHub Pages 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)와 [GitHub 개인정보 처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)을 확인해 주세요.

운영자는 사용자의 정보를 판매하거나 맞춤형 광고에 이용하지 않습니다. 지원 문의 정보는 답변과 문제 해결에 필요한 범위에서만 접근·사용하며, 법령에 따른 의무가 있는 경우를 제외하고 해당 목적 외로 제3자에게 제공하지 않습니다.
